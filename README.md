# John Ripper Enterprise - Official Website

Welcome to the official repository for the John Ripper Enterprise web platform. This project is a full-scale web application built with **Next.js**, featuring seamless **M-Pesa integration** for logistics and enterprise payments.

## 🚀 Features
- **Enterprise Dashboard:** Comprehensive management for logistics and orders.
- **M-Pesa Express Integration:** Secure, real-time STK push payments via Safaricom Daraja API.
- **Responsive UI:** Professional design tailored for desktop and mobile users.
- **Order Tracking:** Real-time status updates for customers and operators.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **API:** Safaricom Daraja (M-Pesa)
